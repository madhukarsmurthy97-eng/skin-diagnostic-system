

Skin Disease Diagnosis & Treatment Multi-Agent System
Project Overview

This project is a multi-agent AI system designed for dermatology support. It combines:

CNN Agent (SkinClassifier) – Uses ResNet18 (transfer learning) to classify skin images.

LLM Agent (TreatmentLLMAgent) – Generates dynamic, personalized treatment advice using a local LLM (GPT-2).

The system allows patients to upload images of their skin conditions, automatically predicts the condition with a confidence score, and provides AI-assisted treatment advice. All results are stored in a local database for tracking and analysis.

Features

Image-based skin condition diagnosis using a CNN (ResNet18).

Personalized treatment advice generated by an LLM agent.

Confidence-based recommendations (low-confidence predictions prompt dermatologist consultation).

Database logging of patient data, predictions, and advice.

Interactive web interface powered by Gradio.

## Features

Agents
1. CNN Agent (SkinClassifier)

Purpose: Classifies skin images into 7 categories:
Acne, Eczema, Psoriasis, Rosacea, Fungal Infection, Vitiligo, Healthy.

Technology: PyTorch, ResNet18 with transfer learning.

Output: Predicted condition + confidence score.

2. LLM Agent (TreatmentLLMAgent)

Purpose: Generates dynamic, personalized treatment advice based on the predicted condition and confidence.

Technology: HuggingFace Transformers, GPT-2 pipeline.

Output: Short treatment steps in natural language.

Database

Type: SQLite

Stored Information: Patient name, image path, predicted condition, confidence, LLM-generated advice, timestamp.

Location: patients.db (created automatically on first run)

Evaluation

CNN Agent: Accuracy and confidence scores for image classification.

LLM Agent: Manual evaluation of advice correctness and safety.

Database Logging: Ensures traceability of predictions and recommendations.
